**多商户**网购平台：商家自助入驻、店铺商品、跨店购物车按店拆单分别支付，
平台管理员负责商户审核与全平台监管（**不做佣金 / 分账 / 结算**）。
Spring Boot 单体 + Vue 3 前后端分离，经 **gRPC 接入 RAG 客服智能体**（外部项目 `rag_helper`）。

**定位**：学习练手 / 简历项目，不是真实运营 —— 无真实支付、无高并发要求。

## 技术栈

| 层 | 选型 |
|---|---|
| 后端 | Spring Boot 4.1.1 · JDK 17 · **Spring MVC** |
| 数据访问 | **MyBatis-Plus** 3.5.17 —— ✅ 已在 Boot 4.1.1 上验证通过 |
| 数据库 | MySQL 8 —— 复用本机共用容器，库名 `its_mygo` |
| 缓存 | Redis 7 —— 复用本机共用容器，key 前缀 `its-mygo:`（**必须带 TTL**） |
| 表结构迁移 | Flyway 12.4.0 —— **须用 `spring-boot-starter-flyway`**，详见 [HANDOFF §5.1](HANDOFF.md) |
| 安全 | Spring Security 7 + JWT（jjwt 0.13.0，HS256，密码 BCrypt）—— ✅ 已接入 |
| 对象存储 | MinIO 8.5.17 —— 复用本机共用容器，bucket `its-mygo-product-images`，✅ 已接商品图上传 |
| 消息队列 | RabbitMQ 4（AMQP + 管理台）—— 超时未支付订单自动取消，✅ 已接 |
| 客服链路 | 原生 `grpc-java` + `protobuf-maven-plugin`（不用 starter，Boot 4 未适配） |
| API 文档 | springdoc-openapi |
| 日志 | SLF4J + Logback；控制台带 traceId/userId，prod 输出 JSON 文件并保留 14 天 |
| 前端 | Vue 3 + Vite + TypeScript + Element Plus + Pinia + Vue Router |
| 构建 | Maven（**单模块**） |

> ⚠️ **Spring Boot 4 的坑不少** —— 自动配置被拆成独立模块（Flyway 要换官方 starter）、
> Jackson 升到 **3**（包名从 `com.fasterxml.jackson` 变成 `tools.jackson`）、
> `AutoConfigureMockMvc` 换了包路径。动手前先读 [HANDOFF §5](HANDOFF.md)。

## 架构

```
浏览器 ──HTTPS──> Java 单体（登录、权限、页面、SSE 转发）
                    │  gRPC（内网，问答链路）
                    ▼
              Agent 服务（rag_helper）· 8003
                    │  HTTP 工具回调（X-Agent-Ticket，内网）
                    └──────────> Java /internal/agent/**
```

需要实时数据时（如查订单），agent 会反向回调 Java 的内部工具接口；
票据由 Java 每次对话签发，只走 gRPC metadata，不进模型上下文。

**三条边界**（来自 `rag_helper` 的规划，本项目不能自行更改）：

1. 浏览器只跟 Java 说话
2. Agent 服务只在内网、只允许本单体访问
3. 知识库上传是 agent 服务的管理端行为，本平台不做

**对接契约**以 `rag_helper/evolution-plan.md` §5/§6 与 `rag_helper/proto/agent.proto` 为唯一权威。

## 快速启动（Docker）

前置：Docker Desktop。

```bash
./deploy.sh
```

Windows PowerShell 用 `./deploy.ps1`，参数相同。

打开 `http://localhost:8088`。首次会自动生成 `.env`、管理员密码，并导入 44 个演示商品。
停止用 `./deploy.sh down`；想跳过演示数据用 `./deploy.sh up --no-seed`。

联合客服智能体（两个仓库同级）：

```bash
cd ../rag_helper && ./deploy.sh joint
```

端口、环境变量、手工 Compose、镜像源等问题见 [docs/deployment.md](docs/deployment.md)。

**交易闭环已通**：浏览商品 → 加购 → 下单（扣库存）→ 支付 → 发货 → 收货，
以及取消、超时自动取消、退款（申请 → 审核 → 回滚库存）。
**超时关单（M17）**：下单事务提交后发 RabbitMQ 延迟消息，30 分钟未支付自动取消、
回滚库存并退券；消费端按订单状态幂等，数据库扫描兜底，MQ 不可用也不影响下单。
**订单状态**对外显示为：待支付 → 待发货 → 待收货 → 已完成；底层枚举仍是
`PENDING_PAYMENT / PAID / SHIPPED / COMPLETED`，老数据无需迁移。
商品支持**多规格 SKU**（每个规格组合独立价格与库存），也支持「立即购买」直达结算。
**多商户**：商家入驻后管理本店商品/订单，跨店购物车按店拆单、分别支付；
**管理端**具备商户审核、分类维护、商品管理、发货与退款审核、平台券/店铺券、评价管理，
以及**数据概览**（今日成交 / 待发货 / 待退款 / 待审核商户 / 低库存、近 7 天趋势）；
订单支持关键词（订单号 / 收货人 / 电话 / 运单号）与下单日期筛选、按条件导出 CSV；
退款会记录原因、申请时间与处理时间，顾客端和管理端都能看到。
**在线聊天**：商品详情 / 店铺主页 / 订单详情可「联系卖家」，按店建立会话；
支持文本、图片、商品卡片、订单卡片，SSE 实时推送与未读角标、已读回执、商家在线状态，
商家离线时可留言；平台自营店的会话由管理员在 `/admin/messages` 统一回复。
顶栏「消息 / 领券中心 / 购物车」显示动态数量角标，为 0 时自动隐藏。
**客服智能体「买小购」**：消息页固定卡片进入对话，Java 经 gRPC 调外部 agent 服务，
流式返回答案、执行流、配图与用量；执行流默认折叠成一行（转圈 + 当前步骤），
点击展开完整过程，历史会话同样可展开；支持停止与历史恢复，会话按用户隔离，
可从「历史」切换跨设备保存的会话。
**订单查询已接真实数据（M7）**：agent 通过 Java 内部接口按订单号或最近订单
查询当前用户的真实订单状态、商品、金额与物流单号，不再返回 mock。
**智能下单 / 退款申请（M9/M10，2026-10-21）**：agent 可以搜索商品、准备订单草稿、
准备退款申请草稿；聊天里会渲染确认卡片，用户点击确认后才由 Java 真正执行。
下单成功后买小购会回复订单号与应付金额，并提示订单状态以订单详情页为准。
**草稿不等于成功**，支付仍需在订单详情页完成。
**催发货（M8，2026-10-22）**：对「待发货（已支付未发货）」的订单，买小购可以生成催发货确认卡；
用户确认后 Java 触发 agent 执行图，**由 agent 调用发送工具**，Java 校验并落库为
AGENT 站内消息；随后买小购回复用户「催发货已完成」、代商家致歉；10 分钟内不重复催。
**催退款（M8 二期，2026-10-23）**：对「退款中（REFUNDING）」的订单，同样的确认卡与
agent 发送链路，提醒商家尽快处理退款；已退款 / 已驳回 / 其他状态不可催，10 分钟内不重复。
**日志（2026-10-24）**：每个请求生成/透传 `X-Trace-Id`，日志带 traceId 与 userId；
生产 profile 输出 JSON 文件（按天 + 100MB 滚动，保留 14 天），并关闭 MyBatis SQL 明细。
**用户管理与审计（M18，2026-10-24）**：管理端可按用户名 / 昵称 / 手机号、角色、状态筛选用户，
禁用后旧登录态立即失效；所有管理端写操作写入独立的 `admin_audit_logs`，
记录操作人、动作、目标、结果、IP 与 traceId，审计页只读查询。
**商户与商品运营（M19，2026-10-24）**：商户列表展示近 30 天成交 / 订单 / 退款 / 在售 / 低库存，

行内调库存，看板低库存入口可直接跳转到已筛选列表。
**品牌专区（M20，2026-10-24）**：44 个商品归入奔图、联想、至像、兄弟、华为、H3C、
Aolynk、RS PRO 八个品牌；首页品牌墙由 `GET /api/products/brands` 驱动，
点击按品牌精确筛选，不再依赖商品名关键词；品牌图标存 MinIO。
**商品图缩略图（M21，2026-10-24）**：上传商品图即生成 400×400 缩略图，
商品与 SKU 保存时图片变化会同步刷新；列表卡片加载缩略图，详情页仍用原图，
存量图可通过管理端回填接口补齐。
**知识库导入（M22，2026-10-25）**：管理员在 `/admin/knowledge` 上传 PDF / Markdown，
按文件内容查重、轮询导入进度、查看已导入文档并撤回；Java 带访问密钥代理到
rag_helper 的 8001 导入服务，浏览器仍只跟 Java 说话，不新增 gRPC 契约。
**密码强度（M23，2026-10-25）**：注册和修改密码的新密码至少 8 位，且必须同时包含
字母和数字；登录不重新校验强度，历史账号（含演示账号 `123456`）仍可登录。
**管理员治理（M24，2026-10-25）**：首次部署用 `BOOTSTRAP_ADMIN_*` 创建首个管理员；

**商户经营看板（M25，2026-10-25）**：商家后台 `/merchant/dashboard` 展示今日成交 /

**AI 导购（M11–M13，2026-10-21）**：新增 product-guide 子 agent；支持按关键词、
分类、价格搜索，关键词不足时语义检索；回复里渲染商品卡（图片 / 价格 / 库存 /

**虚拟物流（M7.5，2026-10-21）**：发货后生成虚拟运单，状态按时间推进，
预计送达时间就是最终送达时间；订单详情页展示四段时间线与腾讯地图，
agent 查订单时能看到「运输中 / 派送中 / 预计 X 送达」。
**发货地址（M7.6，2026-10-21）**：商家在店铺资料页设置发货地址，平台在商户管理
代设（平台自营同一入口）；有坐标时物流地图从「店铺名 + 发货仓」出发，
未解析坐标时回退虚拟转运中心。
