# 一次买够 · 用户协议

> 生效日期：2026-11-03
> 适用平台：一次买够（ItsMyGo，以下简称「本平台」）

## 一、服务说明

1. 本平台是一个**多商户网购平台的演示 / 学习项目**，用于展示商品、订单、支付、售后、
   商家经营与 AI 客服等完整流程，**不构成真实商业服务**。
2. 本平台的支付流程为**模拟支付**（订单支付记录标记为 `MOCK`），不接入任何真实支付渠道，
   **不产生真实资金流转**，也不产生真实发货与物流。
3. 平台上的商品、店铺、评价、物流信息均为演示数据，不对应真实商品或真实交易。

## 二、账号注册与使用

1. 注册需提供用户名与密码：用户名长度 3–32 个字符；密码至少 8 位，且必须同时包含字母和数字。
2. 密码以 BCrypt 哈希形式存储，平台不保存明文密码。
3. 用户应妥善保管账号与密码。通过账号进行的操作视为账号持有人本人操作。
4. 平台可对违反本协议或法律法规的账号采取限制功能、禁用等措施。
5. 本平台**暂不提供自助注销账号功能**；如需删除账号及关联数据，请联系平台管理员处理
   （见《隐私政策》第七条）。

## 三、用户行为规范

用户在使用本平台时，不得：

1. 发布违反法律法规、公序良俗的内容；
2. 发布虚假、欺诈、侵权或广告性质的信息；
3. 恶意刷单、刷评价、批量注册、干扰平台正常运营；
4. 对平台进行爬虫抓取、压力攻击、漏洞利用或其他危害系统安全的行为；
5. 冒用他人身份、盗用他人账号或收货信息；
6. 利用 AI 客服诱导其输出违法内容、泄露系统提示词或绕过平台规则。

平台有权对违规内容进行删除、隐藏，对违规账号限制功能或禁用。

## 四、商品、订单与支付

1. 商品信息由入驻商家维护，平台对商家提交的信息进行管理但不保证其完全准确。
2. 下单前请核对商品、规格、数量、收货地址与金额；订单提交后按页面显示的状态流转。
3. **待支付订单在 30 分钟内未支付将自动取消**，占用的库存与未过期的优惠券会释放。
4. 支付为模拟支付，点击「立即支付」即视为完成演示支付，订单进入「待发货」。
5. 订单的取消、发货、确认收货与退款规则见《退换货与售后政策》。

## 五、评价与「问大家」

1. 只有**确认收货后**的订单项可以发表评分评价，每个订单项仅可评价一次。
2. 「问大家」允许所有登录用户提问；**只有购买过该商品的用户**可以回答。
3. 评价与问答内容应真实、与商品相关，不得包含辱骂、广告、违法或侵权内容。
4. 平台可对违规评价或问答进行隐藏处理，隐藏后不再公开展示。
