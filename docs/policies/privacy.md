# 一次买够 · 隐私政策

> 生效日期：2026-11-03
> 适用平台：一次买够（ItsMyGo，以下简称「本平台」）

本政策说明本平台收集哪些信息、为什么收集、保存多久，以及你可以如何管理这些信息。
本平台是学习 / 演示项目，请勿填写真实的敏感个人信息。

## 一、我们收集的信息

### 1. 账号信息

| 信息 | 是否必填 | 用途 |
|---|---|---|
| 用户名 | 必填 | 登录与展示 |
| 密码 | 必填 | 登录（仅保存 BCrypt 哈希，不保存明文） |
| 昵称 | 选填 | 页面展示、评价与问答中的显示名 |
| 手机号 | 选填 | 个人资料展示 |
| 头像 | 选填 | 个人资料与评价展示（上传至对象存储） |

### 2. 收货与订单信息

- 收货地址：收货人、联系电话、省 / 市 / 区、详细地址、是否默认；
- 订单信息：下单时的收货信息**快照**、商品与规格快照、数量、金额、优惠、物流单号；
- 退款信息：退款原因、申请时间、处理时间；
- 支付记录：支付单号、金额、支付方式（演示环境固定为 `MOCK`）、支付时间。

### 3. 互动信息

- 聊天消息：你与商家、平台客服的会话内容，包括文本、图片、商品卡片与订单卡片；
- 评价：评分、评价文字、关联的订单项；
- 「问大家」：提问与回答内容；
- 收藏与浏览足迹：收藏的商品、浏览过的商品及时间。

### 4. 日志与安全信息

- 请求日志：访问时间、IP、请求路径、响应状态、错误信息；
- 操作审计：管理员对用户、商品、订单、商户等操作的动作、对象与结果；
- 用于登录态与限流的临时数据（如 JWT、限流计数），仅保存在本地缓存中并自动过期。

### 5. AI 客服

使用「买小购」时，你的问题、会话上下文与检索到的商品文档片段会被发送给第三方大模型服务
用于生成回答，会话内容会保存在客服服务的会话存储中。请勿在对话中填写密码、身份证号、
银行卡号等敏感信息。

## 二、我们如何使用信息

1. 提供登录、购物车、下单、支付（模拟）、售后、评价等核心功能；
2. 完成订单履约：向对应商家展示订单所需的收货信息，用于发货与售后处理；
3. 展示聊天、评价、问答、收藏与浏览记录；
4. 保障安全：登录鉴权、限流、防刷、异常排查与操作审计；
5. 改进功能：统计接口性能与错误率（不用于广告画像）。

**本平台不进行广告投放，不出售、不出租你的个人信息。**

## 三、信息的共享

| 对象 | 共享内容 | 目的 |
|---|---|---|
| 入驻商家 | 订单中的收货人、电话、地址、商品与金额 | 履约发货与售后 |
| 第三方大模型服务 | 你在 AI 客服中的问题与会话上下文、知识库片段 | 生成回答 |
| 对象存储服务 | 你上传的头像、聊天图片 | 存储与展示 |
| 地图服务 | 订单收货地址区域 | 展示物流轨迹地图 |

除上述场景及法律法规要求外，平台不会向第三方提供你的个人信息。

## 四、信息的存储与保留

| 数据 | 存储位置 | 保留期限 |
|---|---|---|
| 账号、地址、订单、评价、问答、聊天 | 平台数据库 | 长期保存，删除账号时一并处理 |
| 登录态、限流计数、一次性令牌 | 本地缓存 | 按用途自动过期（秒级到小时级） |
| 应用日志 | 服务器日志文件 | **14 天**（超过自动清理） |
| AI 客服会话 | 客服服务会话存储 | 长期保存，可联系管理员清理 |

## 五、Cookie 与本地存储

1. 浏览器端使用本地存储保存登录令牌与用户信息，用于维持登录状态；
2. AI 客服与知识库页面使用 HttpOnly Cookie（`kb_session`）保存访问凭证；
3. 本平台不使用第三方广告或统计 Cookie。

## 六、你的权利

1. **查看与更正**：在「个人资料」中修改昵称、手机号、头像；在「收货地址」中管理地址。
2. **删除**：可自行删除收货地址、收藏、浏览足迹；评价与问答内容可联系管理员处理。
3. **撤回授权**：退出登录即清除本地登录态；停止使用 AI 客服即停止向模型发送新内容。
4. **注销账号**：本平台**暂不提供自助注销功能**，请联系平台管理员申请删除账号及关联数据。

## 七、未成年人保护

本平台为演示项目，不面向未成年人提供真实商品交易。未成年人应在监护人指导下使用，
请勿填写真实身份信息。

## 八、信息安全

1. 密码使用 BCrypt 哈希保存，登录使用 JWT 鉴权；
2. 管理端与商家端按角色隔离权限，敏感操作写入审计日志；
3. 演示环境可能通过 HTTP 访问，**请勿在公网环境填写真实个人信息**。

## 九、政策更新与联系方式

1. 本政策更新后在平台公示即生效；
2. 如对隐私处理有疑问，请联系平台管理员（管理员账号见部署环境配置）。

> 本政策仅用于学习项目演示，不构成法律意见。
