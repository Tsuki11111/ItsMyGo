# 一次买够 · 商家入驻与经营规范

> 生效日期：2026-11-03
> 适用平台：一次买够（ItsMyGo，以下简称「本平台」）

本平台为多商铺演示项目，**不收取佣金、不进行分账与结算**，也不发生真实交易。
本规范用于说明商家入驻、经营与违规处理的规则。

## 一、入驻条件

1. 注册本平台账号，且账号状态正常；
2. 提交真实、完整的店铺资料；
3. 同意本规范及平台《用户协议》《隐私政策》《退换货与售后政策》。

## 二、入驻资料

申请时需填写：

| 资料 | 要求 |
|---|---|
| 店铺名称 | 必填，最长 64 个字符，全平台唯一 |
| 店铺 Logo | 选填，上传图片 |
| 店铺简介 | 选填，最长 500 个字符 |
| 联系人 | 必填，最长 32 个字符 |
| 联系电话 | 必填，11 位手机号 |

## 三、审核流程

1. 提交申请后店铺进入「待审核」；
2. 平台管理员审核后：
   - **通过**：店铺状态变为「营业中」，可上架商品、接收订单；
   - **驳回**：显示驳回原因，可修改资料后重新提交；
3. 平台可对营业中的店铺执行**禁用**；禁用后店铺与商品对顾客不可见，已产生的订单仍需继续履约。

## 四、商品发布规范

商家发布商品时应当：

1. 商品名称、副标题、详情、规格、图片真实准确，不得夸大或误导；
2. 库存与价格实时维护，不得虚标库存或先涨后降；
3. 一个商品的多规格（SKU）需分别设置价格与库存；
4. 不得发布法律法规禁止销售的商品；
5. 不得发布侵犯他人知识产权、商标权或肖像权的商品与图片；
6. 不得在商品信息中引导用户到平台外交易或留下外部联系方式。

## 五、订单履约

1. **发货时效**：付款后 **24 小时内**完成发货（平台页面展示的承诺）；
2. 发货时填写物流单号，物流信息为演示数据；
3. **退款处理**：顾客申请退款后，商家应及时在「待退款」列表中处理：
   - 同意退款：库存回滚，订单进入「已退款」；
   - 驳回退款：需基于合理理由，订单回到申请前状态；
4. 顾客发起「催发货」「催退款」时，商家会在消息中心收到提醒，应及时响应。

## 六、评价与问答

1. 商家可以查看本店商品的评价，并对明显违规的评价申请隐藏；
2. 商家**不得**通过利诱、威胁等方式干预顾客评价，不得批量刷评；
3. 「问大家」中只有购买过该商品的用户才能回答，商家不得冒充买家回答。

## 七、优惠券

1. 商家可创建店铺优惠券（满减），设置门槛、金额、数量与有效期；
2. 优惠券不得设置虚假原价或无法兑现的承诺；
3. 平台券由平台发放，商家店铺券由商家自行管理。

## 八、结算

本平台为演示项目：

- **不收取佣金、不进行分账与结算**；
- 不接入真实支付渠道，订单支付为模拟流程；
- 商家的销售收入不通过本平台流转。

## 九、违规处理

平台可视情节采取以下措施：

| 措施 | 适用情形 |
|---|---|
| 商品下架 | 商品信息违规、库存或价格异常 |
| 隐藏评价 / 问答 | 内容违规 |
| 警告并限期整改 | 首次轻微违规 |
| 禁用店铺 | 多次违规、严重误导、拒不履约 |
| 清退 | 严重违法或侵害消费者权益 |

商家对处理结果有异议的，可联系平台管理员申诉。

## 十、责任

1. 商家对其发布的商品信息、履约行为与售后处理承担全部责任；
2. 因商家原因导致的纠纷，由商家与顾客协商解决，平台可协助沟通；
3. 本平台为学习项目，不承担商家经营产生的任何法律责任或经济赔偿。

## 十一、规范更新

本规范随平台功能调整更新，更新后在平台公示即生效。

> 本规范仅用于学习项目演示，不构成法律意见，也不构成真实的商家合作协议。
