# 一次买够 · 退换货与售后政策

> 生效日期：2026-11-03
> 适用平台：一次买够（ItsMyGo，以下简称「本平台」）

本平台为演示项目，**支付、发货与退款均为模拟流程，不涉及真实资金**。
以下规则与平台实际的订单状态机一致，用于说明各状态下可以做什么。

## 一、订单状态与可执行操作

| 订单状态 | 买家可执行 | 说明 |
|---|---|---|
| 待支付 | 立即支付 / 取消订单 | 下单后 **30 分钟内未支付自动取消** |
| 待发货 | 取消订单 / 申请退款 / 催发货 | 商家尚未发货 |
| 待收货 | 确认收货 / 申请退款 / 催发货 / 催退款 | 已发货，等待收货 |
| 已完成 | 申请退款 / 评价 | 确认收货后仍可申请退款 |
| 退款中 | 催退款 | 等待商家审核 |
| 已退款 | — | 终态 |
| 已取消 | — | 终态 |

## 二、取消订单

1. 仅**待支付**与**待发货**订单可以取消；已发货后不能取消，只能申请退款。
2. 取消后：
   - 占用的库存自动回滚；
   - 若使用了优惠券且券仍在有效期内，券自动退回账户；已过期的券不再可用。
3. 取消为即时生效，无需商家审核。

## 三、申请退款

### 1. 适用范围

- 待发货、待收货、已完成的订单可以申请退款；
- 待支付订单请直接取消，无需申请退款；
- 已退款或已取消的订单不能再次申请。

### 2. 申请流程

1. 在订单详情点击「申请退款」，**必须填写退款原因**（最多 200 字）；
2. 提交后订单进入「退款中」，等待商家处理；
3. 商家可「同意退款」或「驳回退款」：
   - 同意：订单变为「已退款」，对应 SKU 库存回滚；
   - 驳回：订单回到申请前的状态（待发货 / 待收货 / 已完成）。

### 3. 退款时效

- 平台未对商家审核设置强制时限；你可以在「退款中」状态下使用「催退款」提醒商家；
- 本平台为演示环境，**不会发生真实退款、不会产生真实资金流转**。

### 4. 退款与优惠券

- 退款成功时，订单使用的优惠券按平台规则处理（未过期券退回，已过期券不可用）；
- 退款金额为订单实付金额，不含运费（本平台暂不收取运费）。

## 四、换货

本平台**目前不支持换货**，仅支持取消订单与退款。如需更换商品，请在退款后重新下单。

## 五、发货与物流

1. 平台要求商家在**付款后 24 小时内发货**（页面展示的承诺）。
2. 发货后可在订单详情查看物流轨迹；物流信息为**虚拟模拟数据**，不对应真实快递。
3. 待发货订单超过承诺时效未发货时，可使用「催发货」提醒商家。

## 六、商品质量与描述不符

如商品存在质量问题或与描述不符，请在申请退款时如实填写原因。演示环境下无真实商品，
该场景仅用于展示退款流程。

## 七、争议处理

1. 与商家产生争议时，可先通过「联系卖家」沟通；
2. 沟通无果可联系平台管理员介入；
3. 本平台为学习项目，不提供消费者权益保障或第三方仲裁。

## 八、政策更新

本政策随平台功能调整更新，更新后在平台公示即生效。

> 本政策仅用于学习项目演示，不构成法律意见，也不构成真实的售后服务承诺。
