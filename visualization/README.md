# ItsMyGo · 3D 项目逻辑星图

双击 [`itsmygo-galaxy.html`](itsmygo-galaxy.html) 即可在浏览器打开（`file://` 也能跑）。单文件、纯 Canvas 2D 伪 3D、无外部依赖，不启动后端。

## 这是什么

把 ItsMyGo 的核心链路画成一张「群星」式星图：

- **技术点 = 节点**：56 个节点，分在 9 个系统里（接入与安全 / 商品与搜索 / 购物车与结算 / 订单与支付 / 库存与并发 / 售后与履约 / 消息与通知 / AI 客服与 Agent / 商家与基础设施）。
- **关联 = 连线**：81 条有向关系，覆盖下单主链、库存、支付、售后、Agent 工具与通知。
- **代码 = 可展开的面**：点击节点打开右侧面板，面板里的「可展开的实现」直接摘录自仓库真实文件，并标了文件路径与行号。

## 交互

| 操作 | 效果 |
|---|---|
| 拖拽 | 旋转星图 |
| 滚轮 | 缩放 |
| 点击节点 | 视角平滑聚焦到该节点，并打开代码面板 |
| 搜索框 | 按节点名 / 技术关键词过滤，Enter 聚焦 |
| 左侧图例 | 只看某个系统；再点一次恢复全部 |
| 主线巡游 | 按下单/支付/库存/售后/Agent 的主链路自动巡游 |
| 空格 | 暂停/恢复自动旋转 |
| `/` | 聚焦搜索框 |
| Esc | 关闭面板 |

## 设计说明

- 星图数据在页面内的 `CATS` / `NODES` / `EDGES` / `TOUR` 常量中；改节点、连线直接改这四个数组即可。
- 代码块是**精简摘录**，用于讲解和面试复盘，不是生产源码的完整复制；排查问题以文件路径为准。
- 星图是静态可视化，不读取运行时数据，也不替代链路追踪；运行时 Trace 仍以 `query_runs` / `llm_trace` / 结构化日志为准。
- 移动端默认不自动弹出面板，避免遮挡星图；点节点后再展开。

## 覆盖的主链路

`JWT → 身份快照 → RBAC` → `商品/SKU → 购物车` → `按商户拆单 → buildCheckoutPlan → persistOrders → finishCheckout` → `支付 → 库存预扣/CAS → 超时关单 → 售后/退款` → `通知/SSE` → `gRPC Agent → 草稿 → 用户确认 → Java 执行`。
